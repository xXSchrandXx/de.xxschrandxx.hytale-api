# Setting up Hytale-API
[German](#German) | [English](#English)

## English
1. Install [Hytale-API](https://www.woltlab.com/pluginstore/file/8404-api-wsc-and-hytale/) via the store code, via the package search or as a file upload.
2. Add your servers in the ACP via `Configuration > Hytale > Servers > +`.
3. Install [WSC-Bridge](https://github.com/xXSchrandXx/WSC-Bridge/blob/main/Setup.md) on your Hytale server.

## German
1. Installiere [Hytale-API](https://www.woltlab.com/pluginstore/file/8403-api-wsc-und-hytale/) über den Storecode, über die Paketsuche oder als Dateiupload.
2. Füge deine Server im ACP über `Konfiguration > Hytale > Server > +` hinzu.
3. Installiere [WSC-Bridge](https://github.com/xXSchrandXx/WSC-Bridge/blob/main/Setup.md) auf deinem Hytale-Server.
