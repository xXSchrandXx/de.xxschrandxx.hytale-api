# Setting up Hytale-API
[German](#German) | [English](#English)

## English
1. Install [Hytale-API](https://www.woltlab.com/pluginstore/file/8403-api-wsc-und-hytale/) via the store code, via the package search or as a file upload.
2. Add your servers in the ACP via `Configuration > Hytale > Servers > +`. Come up with your own username and password. You will need it again in step 6 and 7.
3. Download [WSC-Bridge](https://www.curseforge.com/hytale/mods/wsc-bridge) and put it in your `mods` folder.
4. Restart your server.
5. Open the `config.json` in the `WSC-Hytale_WSC-Hytale-Bridge` folder.
6. Set `user` to the user from the entry from step 2.
7. Set `password` to the password from the entry from step 2.
8. Restart your server.

## German
1. Installieren Sie [Hytale-API](https://www.woltlab.com/pluginstore/file/8403-api-wsc-und-hytale/) über den Store-Code, über die Paketsuche oder als Datei-Upload.
2. Fügen Sie Ihre Server im ACP über `Konfiguration > Hytale > Server > +` hinzu. Legen Sie Ihren eigenen Benutzernamen und Ihr Passwort fest. Sie benötigen diese Angaben erneut in den Schritten 6 und 7.
3. Laden Sie [WSC-Bridge](https://www.curseforge.com/hytale/mods/wsc-bridge) herunter und legen Sie es in Ihrem Ordner `mods` ab.
4. Starten Sie Ihren Server neu.
5. Öffnen Sie die Datei `config.json` im Ordner `WSC-Hytale_WSC-Hytale-Bridge`.
6. Setzen Sie `user` auf den Benutzernamen aus Schritt 2.
7. Setzen Sie `password` auf das Passwort aus Schritt 2.
8. Starten Sie Ihren Server neu.
